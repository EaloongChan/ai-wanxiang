# Search engines: what to submit, and what is already done

The site is technically ready (sitemap with `hreflang`, robots.txt that allows everything,
per-page canonical and metadata verified by `npm run seo`). What remains is three accounts.

## Already done in the repository

| Item | Where |
|---|---|
| `sitemap.xml` with en / zh-CN / x-default alternates | generated by `scripts/build.mjs` |
| `robots.txt` allows everything, points at the sitemap | `public/robots.txt` |
| Per-page title, description, canonical, `hreflang`, OG, JSON-LD | asserted by `scripts/seo-audit.mjs` |
| Google site verification token | `data/site.config.json` → `verify.google` |
| Bing site verification token | `data/site.config.json` → `verify.bing` (**empty**, needs a value) |
| IndexNow | `npm run indexnow:seed` — already pushed 21 URLs (Bing, Yandex) |

## Needs a login (three steps, ~10 minutes)

### Google Search Console

1. <https://search.google.com/search-console> → add property `https://www.ealoongchan.top/` (URL prefix).
2. Verify with the HTML tag that is already in the site (token in `data/site.config.json`).
3. Sitemaps → submit `https://www.ealoongchan.top/sitemap.xml`.
4. URL inspection → check three pages: `/`, `/games/lumber-tycoon/`, `/tools/sens-converter/`.

### Bing Webmaster Tools

1. <https://www.bing.com/webmasters> → add site. The quickest route is "import from Google Search Console".
2. If verifying by hand instead, add the token to `data/site.config.json` → `verify.bing`
   (`content="…"` value), run `npm run build`, then deploy.
3. Sitemaps → submit `https://www.ealoongchan.top/sitemap.xml`.

### Baidu

Only worth doing for the Chinese pages, and only after the site is reachable from mainland
China at a reasonable speed. Two obstacles are outside the repository:

- the domain is not ICP-filed and is hosted outside China, which Baidu treats as a negative;
- `.top` is uncommon in Baidu results.

If it is still worth trying: <https://ziyuan.baidu.com> → add site → verify → submit
`https://www.ealoongchan.top/sitemap.xml`. Expect slow indexing, not a quick win.

## After each deploy

```bash
npm run verify:live     # pages, redirects, security headers, plus the SEO assertions against production
```

`verify:live` runs `seo-audit.mjs --live`, so a missing canonical, a broken `hreflang` pair or a
404 share image is caught on the deployed site rather than only locally.

## What to look at after 2–4 weeks

| Question | Where | What "working" looks like |
|---|---|---|
| Are pages indexed? | Search Console → Pages | 20+ of 25 indexed |
| Which queries bring people? | Search Console → Queries | tool names appearing at all |
| Do they stay? | Web Analytics → bounce, session time | tool pages under 75% bounce |
| Does the game convert? | Analytics Engine → `first_rewind` / `game_start` | ≥ 8% |

Thresholds and what to do when they are missed are in `docs/decisions.md`.
